Privacy Policy

This policy covers the Yasron local creator workspace and this public information website, maintained by GitHub user yasaraydemir.

1. Scope and current availability

Yasron is currently a personal, locally operated workspace. Its direct TikTok integration is in Sandbox testing for designated accounts. This website does not offer public account registration or a hosted analytics service.

2. Information the workspace processes

  • Connection information entered or authorized by the operator, including API credentials, access tokens and account identifiers.
  • Authorized social-account identity, public-video identifiers, descriptions, links, publication status and performance counters returned by the platform.
  • Local video files, captions, publishing metadata, approval records, job status and diagnostic information needed to operate the workspace.

The TikTok setup requests basic identity, profile, account statistics and public-video access. A permission being granted does not mean every available field is collected. Data is requested only as implemented and authorized. The current TikTok integration does not read private messages or private videos.

3. Purposes

Data is used to verify the connected account, prepare and track approved publishing jobs, retrieve available performance measurements, display reports and diagnose connection failures. Social data is not sold or used by Yasron for targeted advertising.

4. Storage and protection

Workspace data is stored on the operator’s computer. On Windows, saved connection secrets are protected using Windows DPAPI tied to the local user. This does not encrypt every workspace file. The operator is responsible for device security, backups and access to local files.

5. External services

Authorized API requests are sent to the relevant social platforms. When the operator approves a publishing job, selected media and metadata may be sent to Cloudinary for media hosting and Buffer for distribution, or to a directly connected platform. These providers process data under their own terms and privacy policies. Merely visiting this website does not initiate publishing or connect an account.

This website is hosted on GitHub Pages. GitHub may process technical information such as visitor IP addresses and request logs under its privacy statement. The site adds no analytics scripts, advertising trackers, forms or application cookies.

6. Retention, revocation and deletion

Local records remain until the operator deletes them; this version does not promise an automatic expiry period. To stop platform access, revoke Yasron’s authorization in the platform’s connected-app settings. Revoking access does not automatically erase previously stored records. The operator can remove local credentials and stored records, including any retained backups. Media already sent to external services must be deleted there separately.

7. Questions and requests

Contact the maintainer through the Yasron support repository. Issues are public: post only a general request, never tokens, passwords, private account data or identity documents. A request requiring private information should first arrange a private communication channel with the maintainer.

8. Changes

This policy will be updated when data handling or project availability changes. The date at the top identifies the current published version.
